# Toplet IP 角色 · Seedance 图生视频提示词

## 推荐设置

- 模式：图生视频（首帧使用 `docs/assets/notch-character.png`）
- 模型：Seedance 2.0
- 时长：5 秒
- 比例：9:16
- 镜头：固定
- 运动幅度：中低
- 背景：纯色绿幕，后续在 Electron 中抠成透明视频

## 主提示词

保持参考图中 Toplet IP 角色的身份：大头小身体、半垂黑眼、层次中长黑发、灰色针织上衣、略疲惫但友好的表情，以及暖白、石墨灰、砖红点缀的材质与配色。角色从画面下方自然探出上半身，双前臂轻松趴在画面底部一条不可见的水平组件边缘上；开始 0.4 秒保持安静并看向镜头，随后轻轻拉下一枚砖红色标签，几张极简待办卡片随之展开，再自然收回并恢复初始姿势，方便循环。动作轻盈、细腻，头发和衣袖只有很轻的惯性摆动。固定机位，正面中近景，角色始终位于画面中央偏下，头顶与左右留出安全边距。背景必须是完全均匀、无渐变、无阴影、无反光、无绿色溢色的纯色 #00FF00 绿幕，人物脚下和背后不出现其他物体。

## 负向提示词

不要改变人物长相、发型、眼睛、灰色针织服装和材质；不要变成真人、蓝色机能服角色或其他作者形象；不要增加或减少手指、手臂、饰品；不要出现肢体穿插、手指粘连、面部漂移、嘴型说话、夸张表情、快速动作；不要推拉、摇移、旋转、景深变化或镜头抖动；不要加入桌子、栏杆、房间、风景、文字、字幕、标志、水印、粒子和额外人物；不要裁掉头顶、手掌、手肘和肩膀；不要产生绿幕阴影、渐变、噪点或绿色反光。

## 后期接入说明

Seedance 常规视频不带 Alpha 通道。导出后先用绿幕抠像转为透明 WebM，再放入首页人物模块；首尾姿势一致，可在每次展开时从头播放一次，结束后停在末帧。
